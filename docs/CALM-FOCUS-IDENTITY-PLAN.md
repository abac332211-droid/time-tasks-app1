# TimeTasks — Calm Focus
## مواصفة الهوية البصرية والإطار التنفيذي

> **الاسم الاستراتيجي:** Calm Focus — الإنتاجية الهادئة الواعية  
> **العبارة التعريفية المقترحة:** وقتك بوعي.  
> **الوصف الإنجليزي:** Intentional Productivity  
> **الحالة:** مواصفة معتمدة للتوثيق والتحضير؛ لم يبدأ التنفيذ البصري.  
> **تاريخ تثبيت مرجع الحالة:** 22 نوفمبر 2026.  
> **النطاق:** تطوير المظهر تدريجيًا داخل CSS فقط، دون تغيير سلوك التطبيق أو بنية واجهته.

## 1. الرؤية والهدف

TimeTasks مساحة هادئة تساعد المستخدم على ترتيب يومه، ومعرفة ما يستحق انتباهه الآن، ومتابعة تركيزه وإنجازه دون ضغط أو لوم.

الهوية ليست مجرد «أخضر إسلامي»، بل منتج إنتاجية حديث له شخصية عربية إسلامية أصيلة، ويجمع بين:

- الحداثة التقنية والوضوح العملي.
- الهدوء البصري والمساحات المريحة.
- الانضباط دون توتر أو إشعار المستخدم بالذنب.
- الدفء العربي الإسلامي عبر تفاصيل هندسية خافتة، لا عبر رموز دينية مباشرة أو زخارف كثيفة.

**المبدأ الحاكم:** لا نغيّر سلوكًا مستقرًا أو بنية التطبيق للحصول على تحسين جمالي. أي مطلب بصري لا يمكن تحقيقه ضمن القيود المعتمدة يُرفع للمراجعة بدل الالتفاف على القيود.

## 2. مبادئ تجربة المستخدم

### 2.1 وضوح الأولوية

عند فتح التطبيق ينبغي أن يستطيع المستخدم تمييز ثلاثة أمور بسرعة:

1. المهمة أو الأولوية التي يعمل عليها الآن.
2. الإجراء التالي المتاح له.
3. حالة المؤقت والوقت المتبقي.

هذا ترتيب هرمي بصري مقترح، وليس تصريحًا بإعادة ترتيب عناصر DOM أو تغيير تخطيط الصفحة. يطبق فقط من خلال التنسيق المسموح به داخل CSS وبما يتوافق مع البنية الحالية.

### 2.2 تقليل الضوضاء البصرية

- تقليل العناصر الزخرفية والتباينات التي تنافس المحتوى.
- استخدام لون أساسي واحد للأفعال المهمة، مع ألوان مستقلة للحالات الوظيفية.
- تجميع المعلومات المرتبطة بصريًا دون نقل العناصر أو إخفائها.
- جعل مساحة المهمة والمؤقت مقروءة قبل التفاصيل الثانوية.
- تجنب الحركات المتكررة، المؤثرات المستمرة، والظلال القوية غير الضرورية.

### 2.3 الإنتاجية دون ضغط

- إظهار التقدم والإنجاز بوضوح وهدوء.
- عدم استخدام لغة لونية أو بصرية تعاقب التأخر أو عدم إكمال اليوم.
- عدم تحويل الواجهة إلى لعبة مكافآت أو مؤشرات متنافسة.
- الحفاظ على معنى الحالة الوظيفية: نجاح، تحذير، خطأ، ومعلومة؛ وعدم استبدالها كلها بالأخضر.

### 2.4 حدود الأدلة العلمية

توجد مراجعة منهجية منشورة عام 2025 جمعت 132 مقالة علمية عن ارتباطات اللون والعاطفة، بإجمالي 42,266 مشاركًا من 64 دولة. رصدت ارتباطات بين الأخضر والأخضر المزرق والأزرق والأبيض ومشاعر إيجابية منخفضة الاستثارة، لكنها أوضحت أن كثيرًا من النتائج تقيس ارتباطات اللون بالعاطفة، ولا تثبت أن اللون وحده يُحدث الشعور نفسه في كل سياق.

كما راجعت دراسة منهجية منشورة عام 2024 عدد 41 مقالة حول تصميم التدخلات الرقمية لتكوين العادات، ووجدت شيوع المراقبة الذاتية وتحديد الأهداف والتنبيهات/الإشارات والتغذية الراجعة. هذه استراتيجيات مستخدمة في تدخلات مدروسة، وليست دليلًا على أن لون الواجهة وحده يكوّن عادة أو يزيد الإنتاجية.

بناءً على ذلك، تُعامل الألوان والمبادئ البصرية هنا كقرارات تصميمية قابلة للاختبار، لا كوعود نفسية أو علاجية.

### الطابع العربي الإسلامي

لا تستخدم هلالًا أو مئذنة أو زخارف كثيرة؛ حتى لا يبدو TimeTasks تطبيق أذكار أو تطبيقًا دينيًا متخصصًا.

يظهر الطابع من خلال:

- هندسة إسلامية دقيقة وخافتة، لا تنافس النصوص.
- لون نحاسي معتّق بقدر محدود.
- الخط العربي المناسب للعناوين، دون التضحية بسهولة القراءة.
- قيم الاعتدال والإتقان واحترام الوقت والتوازن في فلسفة الواجهة.

أي نقش أو زخرفة لا يمكن إضافته دون HTML أو أصل صورة جديد لا يُنفذ ضمن مرحلة CSS-only الحالية.

## 6. خريطة متغيرات CSS — دون إنشاء نظام موازٍ

**لا تنشأ مجموعة ثانية متداخلة من المتغيرات.**

قبل التنفيذ:

1. جرد متغيرات CSS الحالية ومواقع تعريفها واستخدامها.
2. الاحتفاظ بأسماء المتغيرات الحالية عندما تؤدي الدور نفسه.
3. بناء جدول mapping من الأسماء الحالية إلى أدوار Calm Focus.
4. إضافة المتغيرات الدلالية الناقصة فقط.
5. عدم إنشاء متغيرين متعارضين للدور نفسه، مثل primary وbrand-primary، دون سبب تقني موثق.
6. اختبار التوافق بحيث لا يتغير المظهر في خطوة الجرد الأولية.

## 7. الخطوط والطباعة العربية

- خط عربي حديث وواضح للنصوص والمهام والحقول والمعلومات الكثيفة.
- Amiri للعناوين المحدودة المناسبة فقط، إذا كان متوفرًا ضمن ملفات وأصول المشروع الحالية.
- أرقام المؤقت بخط واضح مع أرقام ثابتة العرض عند توفر ذلك في الخط الحالي.
- حماية تشكيل الحروف والنقاط والمسافات الرأسية في النصوص العربية.
- اختبار مزج العربية والأرقام والعبارات الإنجليزية داخل السطر الواحد.
- لا تضاف مكتبة أو حزمة أو طلب خط خارجي جديد دون قرار وموافقة منفصلين.
- إذا لم يكن Amiri متاحًا، يستخدم بديل مناسب مؤقتًا بدل إدخال اعتماد جديد تلقائيًا.

عبارة «وقتك بوعي» وعبارة «رتّب أولوياتك وابدأ بهدوء» مقترحتان للهوية والمواد التعريفية فقط. لا تُضافان إلى نصوص التطبيق في هذه المرحلة؛ لأن ذلك يتطلب تغيير HTML أو المحتوى، وهو خارج نطاق CSS-only.

## 8. تطبيق الهوية على الأجزاء الخمسة

الترتيب ملزم، ويُراجع كل جزء قبل الانتقال إلى الذي يليه:

1. **رأس التطبيق:** إبراز هادئ للهوية، وضوح العنوان الموجود، وعدم تحويل الرأس إلى زخرفة أو مساحة طاغية.
2. **الأزرار:** تمييز الفعل الرئيسي والثانوي، وحالات التركيز والضغط والتعطيل. لا تغيير لآلية النقر أو الأبعاد الهندسية المعتمدة.
3. **البطاقات:** أسطح طبيعية وحدود هادئة، وتسلسل بصري يبرز المعلومات المهمة. لا تعديل لبنية البطاقة أو مقاساتها دون إذن منفصل.
4. **المهام:** تمييز النشط والمكتمل دون إضعاف النص. لا يعتمد معنى الاكتمال على اللون وحده أو على خفض opacity بما يضعف القراءة.
5. **المؤقت:** إبراز الوقت والحالة والأزرار الحالية. الحفاظ على دورة المؤقت وسلوكه وتسلسل عناصره.

## 9. حدود التنفيذ البرمجي

### المسموح

- تعديل قواعد CSS الموجودة فقط.
- إذا كانت القواعد داخل index.html، يكون التعديل محصورًا داخل كتلة style الحالية.
- تغيير ألوان وخلفيات وحدود ونصوص CSS المصرح بها.
- إضافة متغيرات CSS دلالية ناقصة بعد الجرد.
- استخدام الخط الموجود فقط، إذا كان مطلوبًا ومتاحًا.

### غير المسموح

- لا تعديل على JavaScript أو معالجات الأحداث أو دوال المهام والمؤقت.
- لا تعديل على عناصر DOM أو ترتيبها أو خصائص HTML أو السمات أو النصوص البنيوية.
- لا تعديل على مفاتيح التخزين أو آليات الحفظ والاستعادة أو التنبيهات.
- لا إضافة Tailwind أو إطار عمل أو مكتبة أو اعتماد خارجي.
- لا تعديل على display أو visibility أو pointer-events أو position أو z-index أو بنية Flex/Grid أو سلوك التمرير أو استقبال النقرات.
- لا تغيير في أبعاد التخطيط أو أحجام عناصر التحكم أو المسافات الهندسية لمجرد التحسين الجمالي.
- إذا ظهر خلل فعلي قابل لإعادة الإنتاج ويتطلب تجاوز هذه القيود، يوثق بدليل ويطلب له إذن منفصل قبل إصلاحه.
- لا إضافة حركة أو مؤثر مستمر أو زخارف كثيفة.
- لا دمج أو نشر أو إصدار أو تغيير main.

**قاعدة تدقيق index.html:** قد يظهر الملف ضمن الملفات المعدلة لأن CSS موجود داخله؛ وهذا مقبول فقط إذا أثبت فحص الفرق أن التغييرات داخل كتلة CSS وحدها. وجود الملف في الفرق لا يجيز تعديل HTML أو DOM أو JavaScript.

## 10. بوابات التنفيذ وترتيبها الإلزامي

### المرحلة 0 — تثبيت النسخة الأساسية وإغلاق متطلبات P0

لا يبدأ العمل على الهوية قبل استكمال هذه المرحلة.
